📊 Cloudflare Web Analytics

Deine Seite verwendet Cloudflare Web Analytics. Die Daten sind in deinem Cloudflare Dashboard verfügbar.
Die Zahlen oben kommen direkt von Cloudflare — falls sie "—" zeigen, fehlt der CF_API_TOKEN in den Netlify Environment Variables.

🔗 Cloudflare Dashboard öffnen  

Um Live-Daten zu sehen: In Netlify Environment Variables CF_API_TOKEN und CF_ZONE_ID setzen. Token erstellen unter: cloudflare.com → My Profile → API Tokens → Web Analytics Read
